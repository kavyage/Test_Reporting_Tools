This tool is to generate testrun execution report  overal test report.

#Tools Integrated:
Testrail for testcases
Jira for defects

#How to use the tool:
update required user emails in Tar.java/testrun.java
run in local - run the tool.java
run as .jar - convert this to jar file and run the jar.
Input to the tool - once tool popup appeared, need to provide the test run url, jira filter url, respective passwords and user email.
*Generated report will be delivered to email inbox given.
